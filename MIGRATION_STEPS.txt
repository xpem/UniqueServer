PASSO 1: ABRIR O VISUAL STUDIO

1. Abra o arquivo: UniqueServer.sln

PASSO 2: ABRIR PACKAGE MANAGER CONSOLE
────────────────────────────────────────────────────────────────────────────────
1. Menu: Tools > NuGet Package Manager > Package Manager Console
2. Aparecerá um painel na parte inferior do Visual Studio


PASSO 3: SELECIONAR O PROJETO CORRETO
────────────────────────────────────────────────────────────────────────────────
No dropdown "Default project:" selecione: MobService

┌─────────────────────────────────────────────┐
│ Default project: MobService               ▼ │
└─────────────────────────────────────────────┘


PASSO 4: CRIAR A MIGRATION
────────────────────────────────────────────────────────────────────────────────
Cole e execute este comando:

EntityFrameworkCore\Add-Migration "AddPetSickness" -Context MobDbCtx

Pressione ENTER

RESULTADO ESPERADO:
Build started...
Build succeeded.
To undo this action, use Remove-Migration.


PASSO 5: REVISAR A MIGRATION GERADA (OPCIONAL)
────────────────────────────────────────────────────────────────────────────────
1. No Solution Explorer, expanda: Mob > Migrations
2. Procure o arquivo: [TIMESTAMP]_AddPetSickness.cs
3. Verifique o conteúdo:

migrationBuilder.AddColumn<int>(
    name: "sickness",
    table: "Pet",
    type: "integer",
    nullable: false,
    defaultValue: 0);

migrationBuilder.AddColumn<long>(
    name: "sickness_timer",
    table: "Pet",
    type: "bigint",
    nullable: false,
    defaultValue: 0L);


PASSO 6: APLICAR AO BANCO DE DADOS
────────────────────────────────────────────────────────────────────────────────
Cole e execute este comando:

EntityFrameworkCore\update-database -Context MobDbCtx

Pressione ENTER

RESULTADO ESPERADO:

PASSO 7: VERIFICAR NO BANCO DE DADOS (OPCIONAL)
────────────────────────────────────────────────────────────────────────────────

╔══════════════════════════════════════════════════════════════════════════════╗
║                          TROUBLESHOOTING COMUM                               ║
╚══════════════════════════════════════════════════════════════════════════════╝

PROBLEMA: "Unable to resolve service for type DbContextOptions"
SOLUÇÃO: Verifique se a connection string está correta no appsettings.json

PROBLEMA: "Build failed"
SOLUÇÃO: Verifique erros de compilação no Output window

PROBLEMA: "Column already exists"
SOLUÇÃO: A migration já foi aplicada antes
         Execute: EntityFrameworkCore\Get-Migration -Context MobDbCtx
         Para ver o histórico

PROBLEMA: Migration gerada vazia
SOLUÇÃO: As mudanças no modelo já estão no banco
         Não é necessário fazer nada

PROBLEMA: Erro de conexão ao banco
SOLUÇÃO: 1. Verifique se o PostgreSQL está rodando
         2. Verifique a connection string
         3. Teste a conexão manualmente
